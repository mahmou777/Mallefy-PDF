# المساهمة في مشروع ملفّي | Contributing to Mallefy PDF

نرحب بجميع المساهمات والاقتراحات لتطوير هذا المشروع! / We welcome all contributions and suggestions!

## كيفية المساهمة / How to Contribute

1. قم بعمل Fork للمستودع (Fork the repository).
2. أنشئ فرعاً لميزتك الجديدة:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. قم بتنفيذ التعديلات واختبارها محلياً:
   - تأكد من عدم تضمين أي مفاتيح سرية مكشوفة في الكود (Ensure zero plain text secrets).
   - تأكد من تشغيل الأدوات واختبارها عبر المتصفح وتطبيق أندرويد.
4. قم بعمل Commit لتغييراتك:
   ```bash
   git commit -m "Add amazing new PDF tool"
   ```
5. ارفع الفرع الخاص بك:
   ```bash
   git push origin feature/amazing-feature
   ```
6. افتح Pull Request جديد وسنقوم بمراجعته ودمجه!

## الإبلاغ عن الأخطاء / Reporting Issues

إذا واجهت أي مشكلة أو كان لديك اقتراح لتحسين الأداء أو الأمان، يُرجى فتح Issue على GitHub مع تفاصيل الخطأ ونسخة المتصفح أو نظام أندرويد المستخدم.
